# Oh My ClaudeCode (OMC) — Antigravity Workspace Plugin

Bu eklenti, [yeachan-heo/oh-my-claudecode](https://github.com/yeachan-heo/oh-my-claudecode) (v5.7.4) çoklu ajan orkestrasyon sistemini bu proje (`haber`) için Antigravity ortamına taşır.

## İçerik
- **48 Beceri (`skills/`)**: `autopilot`, `ralph`, `ralplan`, `deep-interview`, `team`, `execute`, `verify`, `review`, `plan`, `tdd`, `research`, `trace`, `wiki` ve daha fazlası.
- **19 Uzman Ajan (`agents/`)**: `architect`, `executor`, `planner`, `critic`, `debugger`, `security-reviewer`, `test-engineer`, `verifier`, `code-reviewer` vb.
- **Orkestrasyon Kuralları (`rules/AGENTS.md`)**: OMC çalışma prensipleri, doğrulama protokolleri ve anahtar kelime tetikleyicileri.
- **MCP Sunucusu (`mcp_config.json`)**: `omc-tools` (`bridge/mcp-server.cjs`).
