On Zeros and Algorithms for Disordered Systems II: The Antiferromagnetic Ising Model up to Kesten-Stigum arXiv CS (PL, SE, DB, DC, DS)

We give the first polynomial-time algorithm to estimate the partition function of the antiferromagnetic Ising model on the uniformly random d-regular graph to arbitrarily high accuracy for all inverse temperatures up to the Kesten-Stigum threshold. This is the entire regime in which the model is "replica symmetric," and is conjectured to be optimal for polynomial-time counting and sampling. To achieve our algorithmic result, we establish the absence of Fisher zeros for the partition function in a constant-width strip around the interval from 0 up to the Kesten-Stigum threshold, with high probability over the randomness of the input graph.
